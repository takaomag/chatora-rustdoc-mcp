List the types that implement a Rust trait, within the crate that defines it, and what the trait asks of them: its items, each required or provided, whether it is dyn compatible, auto or unsafe, whether it is sealed, and whether it has negative impls. Answers questions such as "which types in tokio implement `AsyncRead`?", "what must I write to implement `Iterator`?" or "can I implement this trait outside its crate?".

`crate`, `version`, `project` and `target` are as for `get_item`: without a version, the project's Cargo.lock decides it, or else the latest release; docs.rs has rustdoc JSON only for releases it built on or after 2025-05-23. `path` is the trait (`tower::Service`, `std::iter::Iterator`); a trait re-exported from another crate is looked up there. `scope` is `crate`, the trait's crate: implementors in other crates (the project's dependencies) are not listed yet, so call `list_impls` on a type to tell whether it implements the trait. `limit` is the most implementors in a page (default 50, at most 200); pass the `cursor` of the previous page, with the same other arguments, for the next.

Returns `provenance` as `get_item` does, and `data`: the trait's `path` and `signature`, its `items` (`name`, `kind`, `provided`), `dyn_compatible`, `auto`, `unsafe`, `sealed` (why only its crate can implement it: a supertrait that is not public; its absence does not mean that others can), `has_negative_impls`, and `implementors`: each with the `type` as Rust writes it (`&T` and `[u8]` too), its `kind` (`trait`, `derive`, `blanket`, `negative` or `auto`) and its `header`. They are sorted by type.
