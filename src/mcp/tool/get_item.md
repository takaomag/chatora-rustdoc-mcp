Look up one item of a Rust crate from docs.rs at an exact version: its signature, where clause, fields or variants, the first paragraph of its documentation, deprecation, and where it is defined. Answers questions such as "what is the signature of `tokio::sync::Mutex::lock` in tokio 1.47.1?", "what fields does this struct have?" or "which crate does this re-export come from?".

Use it for crates on crates.io when the version matters, instead of answering from memory. `crate` is `name@version` with an exact version, such as `tokio@1.47.1`; version requirements and Cargo.lock are not read yet. `path` is the path of the item, such as `tokio::sync::Mutex`, `sync::Mutex` (the crate name is added), or `tokio::sync::Mutex::lock` for a method, an associated item or an enum variant. Public paths, re-exports and definition paths all work. Not for the standard library or for crates that are not on docs.rs. docs.rs has the data only for releases it built on or after 2025-05-23.

Returns `provenance` (the crate, version, target and rustdoc JSON format of the data) and `data`: the canonical path, the kind, the signature as Rust, and for an item re-exported from another crate, the crate and path to look it up with (`reexport_of`).
