List the features of a Rust crate: what each enables, what enables it, and which `default` enables. Answers questions such as "which feature of axum do I enable for websockets?" or "what does tokio's `full` enable?".

`crate`, `version`⟨, `project`⟩ and `target` are as for `get_item`. Pass `feature` for one alone. The features are those of the crate's `[features]` and one for each optional dependency that no feature names as `dep:x`, read from the crates.io index's line of a release⟨, or of the project's other crates from `cargo metadata`, or of a crate of git from its `Cargo.toml`⟩.

Returns `provenance` as `resolve_version` does, `data.default` (the crate's features that `default` enables, through others too), and `data.features`, each with `name`; `enables`, its values as written; `closure`, the crate's features it enables through others too; `dependencies`, what they enable of dependencies (`x?/f` enables `f` only if `x` is enabled otherwise); `enabled_by`, the features that enable it through others too; `default` if `default` enables it; `implicit` for one that an optional dependency makes; ⟪and ⟫`in_docs: false`, when the documentation's build is known, for one that it did not enable, whose items are not in it⟨; and, of a version that the project uses, `enabled_in_project`, whether its build enables it, or `enabled_in_dev_only`⟩. `items`, how many items of its documentation have conditions that mention it, not trait impls (one that only gathers others, as tokio's `full`, has 0). A list longer than 50 is cut, with its `_total`. To enable a feature, pass it or one of its `enabled_by` to Cargo. The list is paged: pass `next_cursor` as `cursor` for the rest. With `feature`, `data.items` lists its items, paged so, entries (by their own condition or re-export) first. `data.docs_rs_json` is as for `resolve_version`.

The features need neither the documentation nor a build⟨, which a crate built here has⟩: while it is fetched⟨ or built⟩, they come at once with `items_pending` and `retry_after_secs`; call again for the items.
