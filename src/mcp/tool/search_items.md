Search the items of a Rust crate by name, `doc(alias)` name (finding `HashMap` by "dict", `Vec::push` by "append"), documentation and path. Answers questions such as "which function in tokio does X?" or "what is the type for Y called?" when the path is not known. Results are ranked and come a page at a time; a result missing from a page is not proof that no such item exists: `page.next_cursor` gets more.

`crate` is the crate to search (optionally `name@version`), with `version`, `project` and `target` as for `get_item`: without a version, the project's Cargo.lock decides it, or else the latest release; docs.rs has rustdoc JSON only for releases it built on or after 2025-05-23. Without `crate`, the project's direct dependencies that its build or its tests use are searched together, at their versions in Cargo.lock; those not ready within 20 seconds are left out (`partial`, with each crate's state in `provenance.sources`) and fetched on, so a later call has them. `crate: "std"` searches std with alloc and core. `query` is the words or path to look for (`Mutex`, `sync::Mutex`, `spawn blocking`); words are matched whole, not as prefixes. `fields` keeps the search to some of `name`, `alias`, `docs` and `path` (default: all). `kind` keeps only items of these kinds, as for `list_module`. `detail` is `brief` (the default: path, kind, signature line, features and the first sentence of the docs) or `normal`. Without `limit`, the first page ends where the scores drop; `limit` (at most 200) sets the size of each page, and `cursor` gets the next with the same other arguments.

Ranking puts first a path that ends as the query does, then the name, then the last word as a name, then an alias, then BM25. Unstable std items are left out.

Returns `provenance` (for several crates, `sources`), `data` with the `query`, the `items` found (each at its canonical path, with `reexport_of` for another crate's item) and, when nothing is found, `did_you_mean` (paths of items with similar names), and `page`.
